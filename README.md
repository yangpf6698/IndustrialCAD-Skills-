# IndustrialCAD-Skills

An Engineering Constraint Library for AI-native CAD Agents.

This repository contains a structured collection of engineering skills, ontology, standards, manufacturing knowledge, materials, simulations, validation rules, domain-specific modules, templates, reports and examples for building AI-driven CAD agents.

## Structure

```
IndustrialCAD-Skills/
├── examples/            # Usage examples
├── ontology/            # Engineering ontology (geometry.yaml)
├── reports/             # Report templates
├── rules/                # Validation rules (e.g., SM-0045)
├── skills/               # Core skills
│   ├── INDEX.md
│   ├── design_intent.skill.md
│   ├── engineering_principles.skill.md
│   ├── geometry_rules.skill.md
│   ├── industrial_constraint_boundary.skill.md
│   └── parameter_management.skill.md
├── templates/            # Prompt DSL templates
├── CONTRIBUTING.md
├── LICENSE
└── README.md
```
